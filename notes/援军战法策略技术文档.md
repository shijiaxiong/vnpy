一、策略概述
1.1 策略名称
援军战法（Relief Force Strategy）

1.2 核心理念
“宁愿卖飞，也不买错！打赢就跑，别追高。”

本策略是一套高度强调本金安全、极小亏损撤退、高盈亏比博弈的交易系统。通过寻找极强的支撑位（撤军线），用极小试错成本博弈反弹或主升浪。

1.3 核心原则
原则	说明
本金安全优先	每笔交易预设亏损控制在1.5%-2%以内
极小止损	跌破撤军线无条件割肉，不抱幻想
高盈亏比	向上盈利空间 : 向下亏损空间 ≥ 2:1
尾盘交易	只在14:40-14:55之间入场，确保K线形态定型
1.4 适用市场环境
市场企稳期或情绪冰点反转期

非单边暴跌主跌浪

板块内有集体止跌迹象

三、模块详细设计
3.1 模块1：龙头筛选模块（SectorLeaderSelector）
3.1.1 功能描述
从板块内所有股票中，识别出符合“龙头”特征的股票作为目标池。

3.1.2 配置参数（LeaderConfig）
参数名	类型	默认值	说明
lookback_days	int	60	回顾周期（天）
top_n	int	3	取前N名为龙头候选
min_market_cap_pct	float	0.7	市值至少板块内前70%
min_roe_pct	float	0.6	ROE至少板块内前60%
max_beta	float	1.2	Beta系数上限
min_turnover_pct	float	3.0	最小换手率（%）
price_above_ma250	bool	True	是否要求站上年线
max_distance_to_ma250	float	0.15	离年线最大偏离度15%
3.1.3 四大维度打分权重
维度	权重	核心指标
领涨得分	30%	超额收益、启动领先度、上涨参与率
抗跌得分	20%	最大回撤防御力、Beta系数、下跌偏离度
带动得分	20%	成交额占比、市值占比、领先相关性
实力得分	30%	市值百分位、ROE百分位、技术回报率
3.1.4 龙头判定标准
判定等级	条件	操作
⭐⭐⭐ 核心龙头	四个维度都在板块前20%	必选
⭐⭐ 候选龙头	三个维度在前20%，一个在前40%	可选
❌ 非龙头	两个以下维度在前20%	排除
3.2 模块2：形态识别模块（BottomPatternRecognizer）
3.2.1 功能描述
识别个股是否形成符合“援军战法”的止跌形态。

3.2.2 配置参数（BottomPatternConfig）
参数名	类型	默认值	说明
consecutive_down_days_min	int	2	最少连跌天数
consecutive_down_days_max	int	4	最多连跌天数
down_amplitude_min	float	0.05	回调最小幅度5%
no_new_low_days	int	2	连续不创新低的天数
volume_shrink_ratio	float	0.7	回调期缩量阈值（≤70%）
volume_expand_ratio	float	1.3	企稳期放量阈值（≥1.3倍）
no_big_yang_line	float	0.06	禁止出现6%以上大阳线
3.2.3 止跌形态判断条件
text
必须同时满足以下所有条件：
1. 连续下跌天数 ∈ [2, 4]
2. 回调幅度 ≥ 5%
3. 连续 2 天以上不创新低
4. 回调期均量 ≤ 前期均量的 70%
5. 企稳期均量 ≥ 5日均量的 1.3 倍
6. 最近10日内未出现涨幅 >6% 的大阳线
3.2.4 输出信息
字段	类型	说明
is_bottom	bool	是否满足止跌形态
consecutive_down_days	int	实际连跌天数
down_amplitude	float	实际回调幅度
no_new_low_days	int	实际不创新低天数
volume_shrink_ratio	float	实际缩量比例
volume_expand_ratio	float	实际放量比例
has_big_yang	bool	是否有大阳线
3.3 模块3：入场时机模块（EntrySignalChecker）
3.3.1 功能描述
在满足止跌形态的基础上，检查当前是否适合入场。

3.3.2 配置参数（EntryConfig）
参数名	类型	默认值	说明
entry_time_start	str	"14:40"	开始买入时间
entry_time_end	str	"14:55"	结束买入时间
min_distance_to_stop	float	0.01	距离止损线至少1%
max_distance_to_stop	float	0.03	距离止损线超过3%放弃
min_risk_reward_ratio	float	2.0	最小盈亏比2:1
target_resistance_lookback	int	60	阻力位回顾周期（天）
3.3.3 入场条件判断
text
必须同时满足：
1. 当前时间 ∈ [14:40, 14:55]
2. 当前价格距离止损线 ∈ [1%, 3%]
3. 盈亏比 = (目标价 - 当前价) / (当前价 - 止损价) ≥ 2
3.3.4 目标价估算方法
方法	计算方式	优先级
前期高点阻力	60日内最高价	优先
60日均线阻力	MA60	次优先
保守估计	当前价 × 1.05	保底
最终目标价 = min(前期高点, MA60, 当前价×1.10)

3.4 模块4：风控管理模块（RiskManager）
3.4.1 功能描述
管理每笔交易的仓位、止损、以及全局风险控制。

3.4.2 配置参数（RiskConfig）
参数名	类型	默认值	说明
stop_loss_pct	float	0.02	固定止损2%
max_loss_per_trade	float	0.02	单笔最大亏损占资金比例
trailing_stop_pct	float	0.03	移动止损3%
atr_multiplier	float	2.0	ATR止损倍数
max_consecutive_losses	int	3	最大连亏次数后暂停
3.4.3 仓位计算公式
text
仓位（股数）= (总资金 × 单笔最大亏损比例) / (入场价 - 止损价)

例如：
总资金 = 100,000元
单笔最大亏损 = 2% = 2,000元
入场价 = 10.00元
止损价 = 9.80元
风险每股 = 0.20元
仓位 = 2,000 / 0.20 = 10,000股
3.4.4 动态止损计算
text
止损价 = max(固定止损价, ATR止损价, 移动止损价)

其中：
- 固定止损价 = 入场价 × (1 - stop_loss_pct)
- ATR止损价 = 入场价 - ATR × atr_multiplier
- 移动止损价 = 持仓期间最高价 × (1 - trailing_stop_pct)
3.4.5 连亏熔断机制
连续亏损次数	动作
1-2次	正常交易
3次	暂停交易，触发熔断
熔断后	需人工确认后调用reset_pause()恢复

六、风险提示与注意事项
6.1 策略局限性
局限性	说明
熊市表现差	连续小亏叠加可能造成较大回撤
流动性风险	小盘股尾盘买入可能产生滑点
幸存者偏差	回测表现可能优于实盘
过拟合风险	参数过度优化可能导致失效
6.2 使用建议
先模拟后实盘：建议先用模拟盘运行1-3个月

分散投资：单策略仓位不超过总资金的30%

定期复盘：每周检查策略表现，警惕收益衰减

人工干预：极端行情下可暂停策略运行

资金管理：建议初始资金不低于50万元（摊薄固定成本）

附录B：常见问题
Q1：止跌形态的条件太严格，选不出股票怎么办？
A：可适当放宽参数，如将volume_shrink_ratio从0.7调至0.8，或将no_new_low_days从2调至1。

Q2：如何判断参数是否过拟合？
A：用样本外数据测试（如2024年数据做样本内，2025年做样本外），若表现差异显著则存在过拟合。

Q3：策略在实盘中滑点影响多大？
A：A股流动性较好的个股（日成交>5000万），滑点通常在0.1%-0.2%之间，建议回测时预留0.2%滑点成本。



## 初步代码实现

``` 
import pandas as pd
import numpy as np
from typing import List, Tuple, Dict, Optional
from dataclasses import dataclass

# ==================== 1. 选股模块：龙头筛选 ====================

@dataclass
class LeaderConfig:
    """龙头筛选配置参数"""
    lookback_days: int = 60           # 回顾周期
    top_n: int = 3                    # 取前N名为龙头候选
    min_market_cap_pct: float = 0.7   # 市值至少板块内前70%
    min_roe_pct: float = 0.6          # ROE至少板块内前60%
    max_beta: float = 1.2             # Beta上限
    min_turnover_pct: float = 3.0     # 最小换手率(%)
    price_above_ma250: bool = True    # 是否要求站上年线
    max_distance_to_ma250: float = 0.15  # 离年线最大偏离度15%

class SectorLeaderSelector:
    """板块龙头识别器"""
    
    def __init__(self, config: LeaderConfig):
        self.config = config
    
    def select_leaders(self, 
                       stock_data: Dict[str, pd.DataFrame],  # {股票代码: 日线DataFrame}
                       sector_data: pd.DataFrame,            # 板块指数日线
                       fundamental_data: pd.DataFrame = None # 基本面数据(市值/ROE)
                       ) -> List[str]:
        """
        返回当前满足龙头条件的股票代码列表
        """
        scores = {}
        sector_return = sector_data['close'].pct_change(self.config.lookback_days)
        
        for code, df in stock_data.items():
            if len(df) < self.config.lookback_days:
                continue
            
            # 基础筛选（快速过滤）
            if not self._pass_basic_filter(df, fundamental_data, code):
                continue
            
            # 四个维度打分
            lead_score = self._calc_lead_score(df, sector_data)
            defend_score = self._calc_defend_score(df, sector_data)
            drive_score = self._calc_drive_score(df, sector_data)
            strength_score = self._calc_strength_score(df, fundamental_data, code)
            
            # 加权总分
            total_score = (0.3 * lead_score + 0.2 * defend_score + 
                           0.2 * drive_score + 0.3 * strength_score)
            scores[code] = total_score
        
        # 返回Top N
        sorted_codes = sorted(scores, key=scores.get, reverse=True)
        return sorted_codes[:self.config.top_n]
    
    def _pass_basic_filter(self, df: pd.DataFrame, fundamental_data, code: str) -> bool:
        """基础门槛过滤"""
        # 换手率条件
        if df['turnover'].iloc[-1] < self.config.min_turnover_pct:
            return False
        
        # 年线条件
        if self.config.price_above_ma250:
            ma250 = df['close'].rolling(250).mean().iloc[-1]
            current_price = df['close'].iloc[-1]
            if current_price < ma250:
                return False
            # 偏离度检查
            if abs(current_price/ma250 - 1) > self.config.max_distance_to_ma250:
                return False
        
        # 基本面条件（如果有数据）
        if fundamental_data is not None and code in fundamental_data.index:
            mkt_cap_pct = fundamental_data.loc[code, 'mkt_cap_percentile']
            roe_pct = fundamental_data.loc[code, 'roe_percentile']
            if mkt_cap_pct < self.config.min_market_cap_pct:
                return False
            if roe_pct < self.config.min_roe_pct:
                return False
        
        return True
    
    def _calc_lead_score(self, stock_df: pd.DataFrame, sector_df: pd.DataFrame) -> float:
        """维度1：领涨得分（0-100）"""
        period = self.config.lookback_days
        
        # 超额收益
        stock_ret = stock_df['close'].pct_change(period).iloc[-1]
        sector_ret = sector_df['close'].pct_change(period).iloc[-1]
        excess_ret = stock_ret - sector_ret
        excess_score = min(100, max(0, (excess_ret + 0.3) / 0.6 * 100))  # 映射 -0.3~0.3 -> 0~100
        
        # 启动领先：首次突破20日高点的相对时间
        stock_high20 = stock_df['high'].rolling(20).max()
        sector_high20 = sector_df['high'].rolling(20).max()
        stock_break_date = (stock_high20 > stock_high20.shift(1)).idxmax()
        sector_break_date = (sector_high20 > sector_high20.shift(1)).idxmax()
        lead_days = (sector_break_date - stock_break_date).days if pd.notna(stock_break_date) else 0
        lead_score = min(100, max(0, 100 - lead_days * 10))
        
        # 上涨参与率
        up_days = sector_df['close'].pct_change() > 0
        up_participation = (stock_df.loc[up_days, 'close'].pct_change() > 0).mean() * 100
        
        return excess_score * 0.5 + lead_score * 0.3 + up_participation * 0.2
    
    def _calc_defend_score(self, stock_df: pd.DataFrame, sector_df: pd.DataFrame) -> float:
        """维度2：抗跌得分（0-100）"""
        period = self.config.lookback_days
        
        # 最大回撤防御力
        stock_mdd = (stock_df['close'] / stock_df['close'].expanding().max() - 1).min()
        sector_mdd = (sector_df['close'] / sector_df['close'].expanding().max() - 1).min()
        defense_ratio = 1 - (stock_mdd / sector_mdd) if sector_mdd < 0 else 0.5
        defense_score = min(100, max(0, defense_ratio * 100))
        
        # Beta系数
        stock_ret = stock_df['close'].pct_change().dropna()
        sector_ret = sector_df['close'].pct_change().dropna()
        aligned = pd.concat([stock_ret, sector_ret], axis=1).dropna()
        if len(aligned) > 10:
            beta = np.cov(aligned.iloc[:,0], aligned.iloc[:,1])[0,1] / np.var(aligned.iloc[:,1])
            beta_score = (1 - min(1, max(0, beta / 2))) * 100  # Beta=0得100分，Beta=2得0分
        else:
            beta_score = 50
        
        # 下跌偏离度
        down_days = sector_ret < 0
        if down_days.sum() > 0:
            down_deviation = (stock_ret[down_days] - sector_ret[down_days]).mean()
            deviation_score = min(100, max(0, 100 + down_deviation * 200))  # -0.5%得200分截断
        else:
            deviation_score = 50
        
        return defense_score * 0.4 + beta_score * 0.3 + deviation_score * 0.3
    
    def _calc_drive_score(self, stock_df: pd.DataFrame, sector_df: pd.DataFrame) -> float:
        """维度3：带动板块得分（0-100）"""
        period = min(60, len(stock_df) - 1)
        
        # 成交额占比
        avg_volume_stock = stock_df['volume'].iloc[-period:].mean()
        avg_volume_sector = sector_df['volume'].iloc[-period:].mean()
        volume_ratio = avg_volume_stock / avg_volume_sector if avg_volume_sector > 0 else 0
        volume_score = min(100, volume_ratio * 100)  # 10%占比得100分
        
        # 市值占比（简化：用成交额代理）
        market_cap_score = volume_score * 0.8
        
        # 领先效应（简化版：个股涨幅能预测次日板块）
        stock_ret = stock_df['close'].pct_change()
        sector_ret = sector_df['close'].pct_change()
        lead_corr = stock_ret.shift(1).corr(sector_ret) if len(stock_ret) > 10 else 0
        corr_score = max(0, min(100, (lead_corr + 0.5) * 100))
        
        return volume_score * 0.4 + market_cap_score * 0.3 + corr_score * 0.3
    
    def _calc_strength_score(self, stock_df: pd.DataFrame, fundamental_data, code: str) -> float:
        """维度4：综合实力得分（0-100）"""
        # 市值实力（从外部数据获取，若无数据给默认分）
        if fundamental_data is not None and code in fundamental_data.index:
            mkt_score = fundamental_data.loc[code, 'mkt_cap_percentile'] * 100
            roe_score = fundamental_data.loc[code, 'roe_percentile'] * 100
        else:
            # 无基本面数据时，用技术指标替代
            mkt_score = 50
            roe_score = 50
        
        # 技术实力：过去一年总回报率
        if len(stock_df) >= 250:
            tech_ret = (stock_df['close'].iloc[-1] / stock_df['close'].iloc[-250] - 1)
            tech_score = min(100, max(0, (tech_ret + 0.5) / 1.5 * 100))
        else:
            tech_score = 50
        
        return mkt_score * 0.4 + roe_score * 0.4 + tech_score * 0.2


# ==================== 2. 形态识别模块：止跌信号 ====================

@dataclass
class BottomPatternConfig:
    """止跌形态识别配置"""
    consecutive_down_days_min: int = 2      # 最少连跌天数
    consecutive_down_days_max: int = 4      # 最多连跌天数
    down_amplitude_min: float = 0.05        # 回调最小幅度5%
    no_new_low_days: int = 2                # 连续不创新低的天数
    volume_shrink_ratio: float = 0.7        # 回调期缩量到前期均量的70%以下
    volume_expand_ratio: float = 1.3        # 企稳期放量到5日均量的1.3倍以上
    no_big_yang_line: float = 0.06          # 不能有超过6%的大阳线

class BottomPatternRecognizer:
    """止跌形态识别器"""
    
    def __init__(self, config: BottomPatternConfig):
        self.config = config
    
    def is_bottom_pattern(self, df: pd.DataFrame) -> Tuple[bool, Dict]:
        """
        判断是否形成止跌形态
        返回：(是否满足, 详细信息)
        """
        if len(df) < 20:
            return False, {}
        
        recent = df.iloc[-15:]  # 最近15日数据
        result = {}
        
        # 条件1：连续回调2-4天
        down_days = self._count_consecutive_down(recent)
        result['consecutive_down_days'] = down_days
        if not (self.config.consecutive_down_days_min <= down_days <= self.config.consecutive_down_days_max):
            return False, result
        
        # 条件2：回调幅度达标
        down_amplitude = self._calc_down_amplitude(recent)
        result['down_amplitude'] = down_amplitude
        if down_amplitude < self.config.down_amplitude_min:
            return False, result
        
        # 条件3：近期不再创新低
        no_new_low = self._check_no_new_low(recent)
        result['no_new_low_days'] = no_new_low
        if no_new_low < self.config.no_new_low_days:
            return False, result
        
        # 条件4：回调期缩量
        volume_shrink = self._check_volume_shrink(recent)
        result['volume_shrink_ratio'] = volume_shrink
        if volume_shrink > self.config.volume_shrink_ratio:
            return False, result
        
        # 条件5：企稳期温和放量
        volume_expand = self._check_volume_expand(recent)
        result['volume_expand_ratio'] = volume_expand
        if volume_expand < self.config.volume_expand_ratio:
            return False, result
        
        # 条件6：没有大阳线透支
        has_big_yang = self._check_no_big_yang(recent)
        result['has_big_yang'] = has_big_yang
        if has_big_yang:
            return False, result
        
        return True, result
    
    def _count_consecutive_down(self, df: pd.DataFrame) -> int:
        """统计最近连续下跌天数"""
        ret = df['close'].pct_change()
        count = 0
        for i in range(len(ret)-1, 0, -1):
            if ret.iloc[i] < 0:
                count += 1
            else:
                break
        return count
    
    def _calc_down_amplitude(self, df: pd.DataFrame) -> float:
        """计算最近一波下跌幅度"""
        recent_high = df['high'].iloc[:-self.config.consecutive_down_days_max].max()
        recent_low = df['low'].iloc[-self.config.consecutive_down_days_max:].min()
        return (recent_high - recent_low) / recent_high
    
    def _check_no_new_low(self, df: pd.DataFrame) -> int:
        """检查连续不创新低的天数"""
        lows = df['low'].values
        count = 0
        current_low = lows[-1]
        for i in range(len(lows)-2, -1, -1):
            if lows[i] <= current_low:
                count += 1
                current_low = lows[i]
            else:
                break
        return count
    
    def _check_volume_shrink(self, df: pd.DataFrame) -> float:
        """检查回调期缩量程度（越小声越好）"""
        down_period = df.iloc[-self.config.consecutive_down_days_max:]
        down_avg_vol = down_period['volume'].mean()
        
        prev_avg_vol = df.iloc[-60:-self.config.consecutive_down_days_max]['volume'].mean()
        return down_avg_vol / prev_avg_vol if prev_avg_vol > 0 else 1
    
    def _check_volume_expand(self, df: pd.DataFrame) -> float:
        """检查企稳期放量程度（越大越好）"""
        stable_period = df.iloc[-self.config.no_new_low_days:]
        stable_avg_vol = stable_period['volume'].mean()
        
        ma5_vol = df['volume'].rolling(5).mean().iloc[-1]
        return stable_avg_vol / ma5_vol if ma5_vol > 0 else 0
    
    def _check_no_big_yang(self, df: pd.DataFrame) -> bool:
        """检查是否最近出现过大的阳线"""
        recent = df.iloc[-10:]
        for i in range(len(recent)):
            if recent['close'].iloc[i] > recent['close'].iloc[i-1] * (1 + self.config.no_big_yang_line):
                return True
        return False


# ==================== 3. 时机判断模块：入场条件 ====================

@dataclass
class EntryConfig:
    """入场时机配置"""
    entry_time_start: str = "14:40"       # 开始买入时间
    entry_time_end: str = "14:55"         # 结束买入时间
    min_distance_to_stop: float = 0.01    # 距离止损线至少1%才考虑
    max_distance_to_stop: float = 0.03    # 距离止损线超过3%则放弃
    min_risk_reward_ratio: float = 2.0    # 最小盈亏比2:1
    target_resistance_lookback: int = 60  # 阻力位回顾周期

class EntrySignalChecker:
    """入场信号检查器"""
    
    def __init__(self, config: EntryConfig):
        self.config = config
    
    def check_entry_signal(self, 
                          df: pd.DataFrame, 
                          stop_loss_price: float,
                          current_time: str = "14:50") -> Tuple[bool, Dict]:
        """
        检查是否满足入场条件
        返回：(是否可以入场, 详细信息)
        """
        result = {}
        
        # 条件1：时间检查
        result['is_tail_time'] = self._is_tail_trading_time(current_time)
        if not result['is_tail_time']:
            return False, result
        
        # 条件2：价格位置检查
        current_price = df['close'].iloc[-1]
        distance_to_stop = (current_price - stop_loss_price) / stop_loss_price
        result['distance_to_stop'] = distance_to_stop
        
        if distance_to_stop < self.config.min_distance_to_stop:
            return False, result
        if distance_to_stop > self.config.max_distance_to_stop:
            return False, result
        
        # 条件3：盈亏比检查
        target_price = self._estimate_target_price(df)
        result['target_price'] = target_price
        result['current_price'] = current_price
        result['stop_loss'] = stop_loss_price
        
        win_ratio = (target_price - current_price) / (current_price - stop_loss_price)
        result['risk_reward_ratio'] = win_ratio
        
        if win_ratio < self.config.min_risk_reward_ratio:
            return False, result
        
        return True, result
    
    def _is_tail_trading_time(self, current_time: str) -> bool:
        """检查是否为尾盘交易时间"""
        return self.config.entry_time_start <= current_time <= self.config.entry_time_end
    
    def _estimate_target_price(self, df: pd.DataFrame) -> float:
        """估算目标价位（阻力位）"""
        current_price = df['close'].iloc[-1]
        
        # 方法1：前期高点阻力
        high_60 = df['high'].rolling(self.config.target_resistance_lookback).max().iloc[-1]
        
        # 方法2：60日均线阻力
        ma60 = df['close'].rolling(60).mean().iloc[-1]
        
        # 取较低者作为目标（更保守）
        target = min(high_60, ma60) if pd.notna(high_60) and pd.notna(ma60) else current_price * 1.05
        
        # 确保目标至少比当前价格高
        return max(target, current_price * 1.02)


# ==================== 4. 风控模块：止损/止盈 ====================

@dataclass
class RiskConfig:
    """风控参数配置"""
    stop_loss_pct: float = 0.02        # 固定止损2%
    max_loss_per_trade: float = 0.02   # 单笔最大亏损占总资金比例
    trailing_stop_pct: float = 0.03    # 移动止损3%
    atr_multiplier: float = 2.0        # ATR止损倍数
    max_consecutive_losses: int = 3    # 最大连续亏损次数后暂停

class RiskManager:
    """风控管理器"""
    
    def __init__(self, config: RiskConfig):
        self.config = config
        self.consecutive_losses = 0
        self.is_paused = False
    
    def calculate_position_size(self, equity: float, entry_price: float, stop_price: float) -> int:
        """
        根据损失金额计算仓位（单位：股）
        """
        risk_per_share = entry_price - stop_price
        if risk_per_share <= 0:
            return 0
        
        max_loss_amount = equity * self.config.max_loss_per_trade
        shares = int(max_loss_amount / risk_per_share)
        
        return shares
    
    def get_dynamic_stop_price(self, entry_price: float, atr: float, current_high: float) -> float:
        """
        获取动态止损价格（支持移动止损）
        """
        # 初始止损
        init_stop = entry_price * (1 - self.config.stop_loss_pct)
        atr_stop = entry_price - self.config.atr_multiplier * atr
        
        # 移动止损：基于滚动最高价
        trailing_stop = current_high * (1 - self.config.trailing_stop_pct)
        
        return max(init_stop, atr_stop, trailing_stop)
    
    def update_after_trade(self, is_win: bool):
        """交易结束后更新状态"""
        if is_win:
            self.consecutive_losses = 0
        else:
            self.consecutive_losses += 1
        
        if self.consecutive_losses >= self.config.max_consecutive_losses:
            self.is_paused = True
    
    def reset_pause(self):
        """重置暂停状态"""
        self.is_paused = False
        self.consecutive_losses = 0


# ==================== 5. 主策略引擎 ====================

@dataclass
class StrategyConfig:
    """策略总配置"""
    leader_config: LeaderConfig
    bottom_config: BottomPatternConfig
    entry_config: EntryConfig
    risk_config: RiskConfig
    max_hold_days: int = 10           # 最大持仓天数
    min_trades_per_day: int = 0       # 每日最少交易次数
    max_trades_per_day: int = 3       # 每日最多交易次数

class ReliefForceStrategy:
    """援军战法主策略"""
    
    def __init__(self, config: StrategyConfig):
        self.config = config
        self.leader_selector = SectorLeaderSelector(config.leader_config)
        self.pattern_recognizer = BottomPatternRecognizer(config.bottom_config)
        self.entry_checker = EntrySignalChecker(config.entry_config)
        self.risk_manager = RiskManager(config.risk_config)
        
        self.positions = {}  # {股票代码: {entry_price, shares, stop_price, entry_date}}
        self.trade_log = []
    
    def on_daily_data(self,
                      date: str,
                      stock_data: Dict[str, pd.DataFrame],
                      sector_data: pd.DataFrame,
                      fundamental_data: pd.DataFrame = None,
                      current_time: str = "14:50") -> List[Tuple[str, float, int]]:
        """
        每日调用，返回生成的交易信号
        返回格式：[(股票代码, 买入价, 买入数量), ...]
        """
        if self.risk_manager.is_paused:
            return []
        
        signals = []
        current_equity = self._calc_current_equity()
        
        # 步骤1：识别当前龙头股
        leaders = self.leader_selector.select_leaders(
            stock_data, sector_data, fundamental_data
        )
        
        # 步骤2：对每个龙头检查形态和入场信号
        for leader_code in leaders:
            if leader_code in self.positions:
                continue  # 已持仓
            
            df = stock_data.get(leader_code)
            if df is None or len(df) < 60:
                continue
            
            # 检查止跌形态
            is_bottom, bottom_info = self.pattern_recognizer.is_bottom_pattern(df)
            if not is_bottom:
                continue
            
            # 计算止损价格（撤军线）
            stop_price = self._calculate_stop_line(df, bottom_info)
            
            # 检查入场信号
            can_enter, entry_info = self.entry_checker.check_entry_signal(df, stop_price, current_time)
            if not can_enter:
                continue
            
            # 计算仓位
            entry_price = df['close'].iloc[-1]
            shares = self.risk_manager.calculate_position_size(
                current_equity, entry_price, stop_price
            )
            
            if shares > 0:
                signals.append((leader_code, entry_price, shares))
                self.positions[leader_code] = {
                    'entry_price': entry_price,
                    'shares': shares,
                    'stop_price': stop_price,
                    'entry_date': date,
                    'target_price': entry_info['target_price']
                }
                
                # 限制每日交易次数
                if len(signals) >= self.config.max_trades_per_day:
                    break
        
        return signals
    
    def on_daily_close(self, date: str, stock_data: Dict[str, pd.DataFrame]) -> List[Tuple[str, float, int]]:
        """
        每日收盘时检查卖出条件
        返回卖出的交易：[(股票代码, 卖出价, 卖出数量), ...]
        """
        exit_signals = []
        
        for code, pos in list(self.positions.items()):
            df = stock_data.get(code)
            if df is None:
                continue
            
            current_price = df['close'].iloc[-1]
            hold_days = (pd.to_datetime(date) - pd.to_datetime(pos['entry_date'])).days
            
            # 检查止损
            if current_price <= pos['stop_price']:
                exit_signals.append((code, current_price, pos['shares']))
                self._record_trade(code, pos, current_price, is_win=False)
                del self.positions[code]
                continue
            
            # 检查止盈
            if current_price >= pos['target_price']:
                exit_signals.append((code, current_price, pos['shares']))
                self._record_trade(code, pos, current_price, is_win=True)
                del self.positions[code]
                continue
            
            # 检查最大持仓天数
            if hold_days >= self.config.max_hold_days:
                exit_signals.append((code, current_price, pos['shares']))
                self._record_trade(code, pos, current_price, is_win=current_price > pos['entry_price'])
                del self.positions[code]
        
        return exit_signals
    
    def _calculate_stop_line(self, df: pd.DataFrame, bottom_info: Dict) -> float:
        """计算撤军线（止损线）"""
        # 取近期不创新低的最低点作为止损线
        lows = df['low'].values
        recent_low = min(lows[-5:])  # 最近5日最低点
        return recent_low * 0.99  # 留0.5%缓冲
    
    def _calc_current_equity(self) -> float:
        """计算当前总资产（简化版，实际应包含未实现盈亏）"""
        # 这里需要外部传入账户数据
        return 1000000  # 暂返回初始资金
    
    def _record_trade(self, code: str, pos: Dict, exit_price: float, is_win: bool):
        """记录交易"""
        self.trade_log.append({
            'code': code,
            'entry_date': pos['entry_date'],
            'entry_price': pos['entry_price'],
            'exit_price': exit_price,
            'pnl_pct': (exit_price - pos['entry_price']) / pos['entry_price'],
            'is_win': is_win
        })
        self.risk_manager.update_after_trade(is_win)


# ==================== 6. 回测评估模块 ====================

class BacktestEngine:
    """回测引擎"""
    
    def __init__(self, strategy: ReliefForceStrategy, initial_capital: float = 1000000):
        self.strategy = strategy
        self.capital = initial_capital
        self.equity_curve = []
        self.holding = {}  # {代码: 持有数量}
    
    def run(self, 
            date_range: Tuple[str, str],
            data_loader) -> pd.DataFrame:
        """
        运行回测
        data_loader: 一个能按日期返回股票数据、板块数据的函数
        """
        dates = pd.date_range(date_range[0], date_range[1], freq='D')
        
        for date in dates:
            # 获取当日数据
            stock_data = data_loader.get_stock_data(date)
            sector_data = data_loader.get_sector_data(date)
            fundamental_data = data_loader.get_fundamental_data(date)
            
            # 先处理卖出（开盘价或盘中触发，简化用收盘）
            exit_signals = self.strategy.on_daily_close(str(date), stock_data)
            for code, price, shares in exit_signals:
                self.capital += price * shares
                if code in self.holding:
                    del self.holding[code]
            
            # 再处理买入
            entry_signals = self.strategy.on_daily_data(
                str(date), stock_data, sector_data, fundamental_data, "14:50"
            )
            for code, price, shares in entry_signals:
                cost = price * shares
                if cost <= self.capital:
                    self.capital -= cost
                    self.holding[code] = shares
            
            # 记录净值
            holding_value = sum(
                stock_data[code]['close'].iloc[-1] * shares 
                for code, shares in self.holding.items() 
                if code in stock_data
            )
            total_value = self.capital + holding_value
            self.equity_curve.append({'date': date, 'total_value': total_value})
        
        return pd.DataFrame(self.equity_curve)
```
