## 十九、低波动长期上升个股精选

从上述高股息个股中，筛选出波动较小、长期处于上升通道的个股。筛选标准：连续多年股息率稳定 > 3%、股价长期趋势向上、经营现金流充沛、行业地位稳固。这些个股属于"红利低波"策略的核心标的，适合作为底仓配置。

### 低波动长期上升个股的核心特征

| 特征 | 说明 |
|------|------|
| 行业属性 | 垄断/寡头竞争格局，准入门槛高（水电、核电、高速、电信、大行） |
| 盈利模式 | 现金流充沛且可预测，重资产折旧完成后利润弹性大 |
| 分红能力 | 连续多年分红率 > 30%，部分达 70%（长江电力），分红意愿强 |
| 机构偏好 | 社保基金、险资、北上资金长期配置，形成"压舱石"效应 |
| 估值安全垫 | 多数 PB < 1 或 PE 处于历史低位，向下空间有限 |
| 政策支撑 | 国企改革市值管理考核、中长期资金入市、分红监管强化 |

### 筛选局限性

- 部分银行股（民生银行、渝农商行等）股息率虽高但基本面偏弱，属于"伪高股息"，未列入低波动上升名单
- 周期股（中远海控、冀中能源等）股息率波动剧烈，不属于低波动范畴
- 东方雨虹等高股息股因行业调整期，短期波动较大，暂未列入
