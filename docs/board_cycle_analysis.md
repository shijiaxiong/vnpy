# A股连板情绪周期分析

## 概述

| 项目 | 内容 |
|------|------|
| 数据来源 | 东方财富涨停板行情 (via akshare) |
| 统计区间 | 2026-04-30 ~ 2026-05-25 |
| 交易日数 | 15 天 |
| 核心指标 | 赚钱效应（当日最高连板数）、砸盘系数（ceil(累加晋级率/40, 1位小数)） |

## 计算公式

- **N板晋级率** = 当日 (N+1) 板数量 / 前一日 N 板数量
- **累加晋级率** = 所有级晋级率之和（百分比）
- **砸盘系数** = ceil(累加晋级率 / 40, 保留1位小数)
- **赚钱效应** = 当日最高连板数
- 统计起点：2板起（不含首板）

## 判定规则

```
主升期  → 赚钱效应爬坡(+) + 砸盘系数低位(<4)，梯队搭建中
高潮期  → 效应创新高 + 系数中高位波动(3~5)，梯队完整扩张
退潮期  → 效应维持高位但系数见顶回落(>5后转跌)，先冲顶再崩塌
朦胧期  → 效应骤降(-50%以上) + 系数冰点(<2)，方向不明等待新周期
```

核心逻辑：**赚钱效应反映"空间有多大"，砸盘系数反映"强度有多猛"。两者同向上升=高潮，系数先行回落=退潮预警，双双触底=朦胧冰点。**
